# 03 插件化架构与格式契约

> 定位：每个格式独立成包的理由、插件契约字段、总入口的职责边界。
> 本文契约已与 `server/plugins/formats/` 实现核对（2026-10-24）。

## 一、插件化目标

每种格式与算法以**插件**形式存在，便于单独增删改某一种；由总入口统一管理。

**要防的退化**：所有格式塞进一个函数、靠 `switch (ext)` 分支 —— 加一种格式就要改主逻辑，删一种要小心不碰坏别的。

## 二、格式包契约

每个格式包导出**一个对象**（`export default` 或 `export const plugin`），字段与方法如下：

### 元数据（静态，启动时不等待任何异步探测）

| 字段 | 说明 |
|---|---|
| `id` | 格式唯一标识（如 `zip` / `tarzst`） |
| `name` | 展示名（如 `ZIP` / `TAR.ZST`） |
| `ext` | 主扩展名（`.zip` / `.tar.gz` / `.tar.zst`） |
| `extAliases` | 别名扩展名数组（用于识别，如 `.tgz`） |
| `mime` | 下载时的 `Content-Type` |
| `levelRange` | 压缩级别范围 `[min, max]` |
| `defaultLevel` | 默认级别 |

### 能力方法

| 方法 | 职责 |
|---|---|
| `available()` | 当前环境能否运行（纯 JS 库看入口是否可加载；外部二进制看命令是否存在） |
| `unavailableReason()` | 不可用时的**明确原因**（前端据此说明为什么置灰） |
| `create(...)` | 创建压缩包，返回可监听进度的对象 |
| `list(archivePath)` | 列出包内条目（用于校验） |
| `test(archivePath)` | 完整性校验（CRC / 解压测试） |
| `estimate(inputSize)` | 预估产物大小（用于空间预检） |
| `extract(...)` | 解压 |

### 注册方式：加目录即注册

注册表**扫描 `server/plugins/formats/*/index.js` 自动注册**，不需要在总入口里手动登记：

```
server/plugins/formats/
├── _shared/        # 跨格式共用（条目安全判定、流工具），不是插件
├── zip/index.js
├── tar/index.js
├── targz/index.js
└── tarzst/index.js
```

规则：

- 目录下必须有 `index.js`，导出符合契约的对象
- `id` 与 `ext` **全局唯一**；冲突时**禁用后来者**，不影响已注册的包
- 加载失败或契约不合法 → 记入 `loadFailures` 并 warn，**其余格式照常工作**
- 启动日志会打印 `format registry loaded`，含已加载格式与失败数

## 三、总入口的三件事

1. **格式注册表**：扫描目录、校验契约、按 `ext` 建索引
2. **任务调度**：队列、并发、进度聚合
3. **空间预检 + 删除决策**：跨格式逻辑不放进格式包

### 边界（关键）

**格式包只负责「怎么压 / 怎么解」，不负责「压完删不删」「任务排不排队」「磁盘够不够」。** 这些属于总入口。

这样加新格式只需写一个包；改删除逻辑不用碰任何格式包。

## 四、可借鉴的开源实现

**tuskermanshu/compress-mcp-server** 的架构值得参考：定义 `CompressionHandler` 接口，各格式（gzip / tar.gz / zip / 7z）实现它，再用**格式注册表**统一调度 —— 正是"接口 + 注册表 + 统一入口"的标准形态，新增格式只加 Handler 并注册，不改入口。

**任务管理**可参考 node-task-manager 的事件驱动模型（`task:progress` 等事件），以及后台任务系统的接入方式（SSE 推送 + 取消信号 + 状态持久化）。

## 五、验收要点（M4）

- 四个格式（zip / tar / tar.gz / tar.zst）都能压
- **新增格式只需加一个包 + 注册，不改主逻辑**
- **删除某个格式包，其余格式不受影响**（关键测试：把 zip 包移走，其余格式仍能正常压）
- `available()` 为 false 时 UI 该选项置灰，并显示 `unavailableReason()`
